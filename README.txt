BIG DAY HOTELS — SITIO WEB ESTÁTICO

Contenido:
- index.html: estructura y contenido de la página.
- styles.css: diseño adaptable a computador, tablet y celular.
- script.js: selector español/inglés y menú móvil.
- assets/: logo y fotografías disponibles del proyecto.

PUBLICAR EN GITHUB PAGES
1. Crea un repositorio en GitHub.
2. Sube el contenido de esta carpeta (no la carpeta ZIP completa dentro de otra carpeta).
3. En GitHub abre Settings > Pages.
4. En Build and deployment selecciona Deploy from a branch.
5. Selecciona la rama main y la carpeta / (root), y guarda.
6. Espera a que GitHub Pages publique el sitio.

NOTAS ANTES DE PUBLICAR
- Esta es una reconstrucción estática basada en las capturas, textos e imágenes disponibles en la conversación. No es una exportación del código interno del editor de ChatGPT ni conserva integraciones privadas del sitio original.
- El mapa muestra la búsqueda general del Lago de Tota, no la ubicación exacta del hotel. Ajusta la ubicación cuando confirmes la dirección o coordenadas.
- El botón de reserva lleva al formulario/sección de contacto de la página. Para recibir reservas reales, conecta el número oficial de WhatsApp o un motor de reservas confirmado.
- Revisa capacidades, servicios, tarifas, políticas y datos de contacto antes de publicar.
