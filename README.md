# Big Day Hotels — sitio web

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube `index.html`, `styles.css`, `script.js`, `README.md` y la carpeta `assets` a la raíz del repositorio.
3. En GitHub, entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. Espera a que GitHub Pages publique el sitio y abre la URL que te muestra.

No cambies los nombres ni la ubicación de los archivos: el HTML busca los estilos en `styles.css`, el JavaScript en `script.js` y las imágenes dentro de `assets/`.

## Antes de publicar

El formulario/flujo de reservas es informativo y no procesa pagos ni confirma disponibilidad. El mapa muestra una búsqueda general de Lago de Tota; configura la ubicación exacta del hotel y los datos de contacto antes de anunciar reservas.
