# Big Day Hotels – GitHub Pages

Todos los archivos están en la raíz del repositorio; no se requiere crear subcarpetas.

## Publicación
1. Sube todos los archivos de este paquete a la raíz del repositorio `BigDayHotels`.
2. En GitHub Pages, publica desde la rama principal y la carpeta `/ (root)`.
3. Espera a que termine la publicación y recarga el sitio con Ctrl/Cmd + Shift + R.
